# Natural Hebrew copy

Rewrite the landing page and main account screens in clear, idiomatic Hebrew: short concrete headings, direct instructions, consistent terminology and fewer translated marketing idioms. Preserve source-coverage limits, manual employer applications, 30-day retention, review before saving, local file processing and separate OpenAI consent. Employer-supplied titles and descriptions remain unchanged.

Examples:

| Before             | After                       |
| ------------------ | --------------------------- |
| מוצאים את החיבור   | מחפשים משרות מתאימות        |
| מדייקים את הכיוון  | מה חשוב לך בעבודה הבאה?     |
| יותר מקום לדבר הבא | יותר קל למצוא את מה שמעניין |
| מחוז במסך          | סינון לפי מחוז              |

The CV picker now has authored Hebrew labels while retaining its native file input, keyboard focus, disabled behavior and existing PDF/DOCX review flow. Native picker text otherwise follows browser language.

Verification: 59 frontend unit tests, both test type checks, production build and 56 production-browser cases. Coverage includes real PDF/DOCX parsing, review/consent boundaries, required setup, filters, preferences, theme initialization, mobile overflow, WCAG axe scans across eight screens, and reduced motion. User-facing assertions were updated to the new wording without changing their functional checks.

Genuine before/after images use the same synthetic account, routes, viewport, theme and fixture data. Still captures use reduced motion. Employer fixture content is synthetic. Existing release evidence remains untouched.
