# Niva UI polish

The refresh keeps the Hebrew RTL structure, routes, data flows and blue identity. It refines the navigation capsule, section labels, hero, card depth, numbered steps, FAQ disclosure controls, action feedback, sidebar selection and input focus. The hero and dashboard reuse the transparent mascot so their artwork works in both themes.

Sections enter once with a 12px movement over 550ms. The three steps stagger by 70ms. Fine-pointer hover lifts cards by 2–3px; buttons have a small press response. Text never fades, content starts visible, no new animation loops, and reduced-motion preferences disable movement. Intersection observers disconnect after the first entry and on navigation away. Browsers without IntersectionObserver show the static content.

Verification: 59 frontend tests, frontend-test and browser type checks, 16 desktop/mobile browser cases, both themes, WCAG axe audits on home/dashboard/jobs/login, overflow, mobile navigation, image loading, finite animations and reduced motion. Production compilation validates the Angular directive and final asset references. Account, authentication, job and server logic are unchanged.

Genuine paired screenshots were captured before editing and after verification, at the same route, viewport, theme and synthetic demo content. Still captures use reduced motion. Desktop: 1440×1000; mobile: 390×844.
